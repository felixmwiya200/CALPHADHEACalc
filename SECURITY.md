# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.4.x   | :white_check_mark: |
| < 3.4   | :x:                |

## Reporting a Vulnerability

The CALPHADHEACalc team takes the security and integrity of scientific computations seriously.

If you believe you have discovered a vulnerability (such as an arbitrary code execution vulnerability, data leakage in export routines, or untrusted script execution), please report it responsibly:

1. **Do not open a public issue.**
2. Report the vulnerability via GitHub Private Vulnerability Reporting (available under the repository's **Security** tab).
3. Alternatively, contact the maintainers directly:
   - **Felix Mwiya**: Lead Developer, SRM University-AP
   - **Prof. (Dr.) Sheela Singh**: Department of Mechanical Engineering, SRM University-AP

Please include:
- A clear description of the vulnerability.
- Steps to reproduce or proof-of-concept code.
- Impact on offline or desktop calculation integrity.

We will acknowledge receipt within 48 hours and work with you to patch the vulnerability before public disclosure.
