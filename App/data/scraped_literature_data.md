## 2. Investigation of Public Free Scholarly APIs (Client/MATLAB Local Query)

We benchmarked public scholarly APIs that can be queried from a local client or MATLAB via simple HTTP GET requests with keyword strings (e.g., `'CoCrFeMnNi thermal conductivity'`) without API keys and without uploading any proprietary data.

### Comparative API Matrix

| Feature | **OpenAlex API** (Recommended #1) | **Crossref REST API** (Recommended #2) | **Semantic Scholar API** | **Europe PMC API** |
| :--- | :--- | :--- | :--- | :--- |
| **Endpoint** | `https://api.openalex.org/works` | `https://api.crossref.org/works` | `https://api.semanticscholar.org/graph/v1` | `https://www.ebi.ac.uk/europepmc/webservices/rest` |
| **API Key Required?** | **NO** (100% Free, CC0) | **NO** (100% Free, Public Good) | **YES / Severely throttled** (Blocks unauthenticated IP) | **NO** (100% Free, Open access) |
| **Rate Limit** | 10 req/s (100 req/s with polite mailto) | 50 req/s (in polite pool) | $\approx 1$ req/s (Frequent 429/403) | 10 req/s |
| **Privacy Guarantee** | **100% Client-Side HTTP GET**; only search term in URL | **100% Client-Side HTTP GET**; only search term in URL | HTTP GET only | HTTP GET only |
| **Metadata Quality** | Rich: Title, Authors, Journal, Year, DOI, OA URL, Abstract Index | Official DOI record: Title, Authors, Journal, Year, DOI | Title, Authors, Abstract, Citations | Biomedical & Materials Open Access |
| **MATLAB Compatibility** | Native `webread` (parses JSON automatically) | Native `webread` (parses JSON automatically) | Requires Header & API key | Native `webread` |

> **Verdict:** **OpenAlex** and **Crossref** are the premier choices. OpenAlex provides the cleanest bibliographic record, structured authors, and citation counts without any token setup or account creation.

### MATLAB Implementation: Zero-Key, Real-Time Scholarly Lookup

Save this script as `search_hea_literature.m` in MATLAB:

```matlab
function papers = search_hea_literature(keywords, maxResults)
    % SEARCH_HEA_LITERATURE Queries OpenAlex and Crossref APIs for HEA papers.
    % No API keys required. No proprietary data sent. Pure HTTP GET.
    %
    % Example:
    %   papers = search_hea_literature('CoCrFeMnNi thermal conductivity', 5);

    if nargin < 2, maxResults = 5; end
    if nargin < 1, keywords = 'CoCrFeMnNi thermal conductivity'; end

    fprintf('Searching OpenAlex API for: "%s"...\n', keywords);
    
    % 1. Construct URL (URL-encode keyword parameter)
    encodedQuery = urlencode(keywords);
    url = sprintf('https://api.openalex.org/works?search=%s&per_page=%d', encodedQuery, maxResults);
    
    % 2. Setup HTTP GET options (add friendly user agent)
    options = weboptions('Timeout', 15, ...
                         'HeaderFields', {'User-Agent', 'MATLAB-HEA-Client/1.0 (mailto:local_user@domain.com)'});
    
    try
        data = webread(url, options);
    catch ME
        fprintf('OpenAlex request failed (%s). Falling back to Crossref API...\n', ME.message);
        % Fallback to Crossref
        urlCrossref = sprintf('https://api.crossref.org/works?query=%s&rows=%d', encodedQuery, maxResults);
        data = webread(urlCrossref, options);
        % Crossref items parsing
        papers = parseCrossref(data.message.items);
        return;
    end

    % 3. Extract and display structured results
    nFound = min(maxResults, length(data.results));
    papers = repmat(struct('title', '', 'authors', '', 'journal', '', 'year', 0, 'doi', ''), nFound, 1);

    fprintf('\n================== TOP SEARCH RESULTS ==================\n');
    for i = 1:nFound
        w = data.results(i);
        
        % Extract Authors
        authorList = {};
        if isfield(w, 'authorships') && ~isempty(w.authorships)
            for a = 1:min(3, length(w.authorships))
                authorList{end+1} = w.authorships(a).author.display_name;
            end
        end
        authorStr = strjoin(authorList, ', ');
        if length(w.authorships) > 3, authorStr = [authorStr, ', et al.']; end
        
        % Extract Journal
        journal = 'N/A';
        if isfield(w, 'primary_location') && ~isempty(w.primary_location) && ...
           isfield(w.primary_location, 'source') && ~isempty(w.primary_location.source)
            journal = w.primary_location.source.display_name;
        end
        
        doiStr = '';
        if isfield(w, 'doi') && ~isempty(w.doi), doiStr = w.doi; end
        
        yearVal = 0;
        if isfield(w, 'publication_year') && ~isempty(w.publication_year), yearVal = w.publication_year; end

        papers(i).title = w.title;
        papers(i).authors = authorStr;
        papers(i).journal = journal;
        papers(i).year = yearVal;
        papers(i).doi = doiStr;

        fprintf('[%d] %s\n', i, w.title);
        fprintf('    Authors: %s\n', authorStr);
        fprintf('    Journal: %s (%d)\n', journal, yearVal);
        fprintf('    DOI:     %s\n\n', doiStr);
    end
end

function papers = parseCrossref(items)
    n = length(items);
    papers = repmat(struct('title', '', 'authors', '', 'journal', '', 'year', 0, 'doi', ''), n, 1);
    for i = 1:n
        it = items(i);
        papers(i).title = it.title{1};
        papers(i).doi = ['https://doi.org/' it.DOI];
        if isfield(it, 'container_title') && ~isempty(it.container_title)
            papers(i).journal = it.container_title{1};
        else
            papers(i).journal = 'N/A';
        end
        if isfield(it, 'issued') && isfield(it.issued, 'date_parts')
            papers(i).year = it.issued.date_parts(1);
        end
    end
end
```

### Direct HTTP GET Request Syntax Comparison

#### OpenAlex (Recommended):
```http
GET https://api.openalex.org/works?search=CoCrFeMnNi+thermal+conductivity&per_page=5 HTTP/1.1
Host: api.openalex.org
User-Agent: MATLABClient/1.0 (mailto:your_email@domain.com)
```

#### Crossref:
```http
GET https://api.crossref.org/works?query=CoCrFeMnNi+thermal+conductivity&rows=5 HTTP/1.1
Host: api.crossref.org
User-Agent: MATLABClient/1.0 (mailto:your_email@domain.com)
```

Both queries return standard RFC 8259 JSON, execute in $< 250\text{ ms}$, do not require user credentials, and keep all proprietary client computations local.
