Solid Solution Formation Rules (Guo & Zhang Criteria)
1. Hume-Rothery & Yang-Zhang Ω Criterion:
A disordered multi-component solid solution forms preferentially over intermetallic compounds when:
  • Atomic size mismatch δ ≤ 6.6%
  • Mixing entropy parameter Ω = (Tm ΔSmix) / |ΔHmix| ≥ 1.1
  • Electronegativity difference Δχ ≤ 0.175
2. Valence Electron Concentration (VEC) Rule:
Predicts the crystalline crystal structure for multi-component alloys:
  • VEC ≥ 8.0 → Stable Face-Centered Cubic (FCC, ductile)
  • 6.87 ≤ VEC < 8.0 → Mixed Dual-Phase Duplex (FCC + BCC)
  • VEC < 6.87 → Body-Centered Cubic (BCC, high strength)
